
# 个人技术文档网站

## 项目简介

使用 VitePress、Markdown、Git 和 GitHub Pages 搭建个人技术文档网站，用于整理学习笔记、AI 技术知识和项目实践成果。

## 项目目标

- 建立可持续维护的个人知识库
- 通过实际操作学习网站搭建与发布
- 展示技术文档组织、内容设计和网站维护能力
- 为未来的 Python 与 AI 应用项目提供展示空间

## 使用技术

| 技术 | 用途 |
| --- | --- |
| VitePress | 生成静态文档网站 |
| Markdown | 编写文档内容 |
| Git | 追踪文件变更 |
| GitHub | 托管项目代码 |
| GitHub Pages | 发布网站 |

## 开发过程记录

### 阶段一：搭建网站

**目标：** 创建一个可以在本地运行并发布到网上的技术文档网站。

**实践内容：**
- 使用 VitePress 创建项目。
- 配置网站标题、描述和导航栏。
- 创建首页、学习笔记、AI 学习中心和关于页面。

**验证方式：**
- 本地启动开发服务器。
- 在浏览器中检查页面和导航链接。
- 执行生产构建，检查是否成功。

### 阶段二：组织内容结构

**目标：** 让不同主题的内容更容易查找。

**实践内容：**
- 建立 AI 学习中心及知识地图。
- 配置侧边栏和页面之间的链接。
- 创建项目作品集和项目详情页。

**验证方式：**
- 检查页面链接是否能够正常打开。
- 检查侧边栏是否显示正确。
- 执行 `npm run build`，检查构建结果。
