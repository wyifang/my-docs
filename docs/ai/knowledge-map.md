# AI 知识地图

本页面用于梳理 AI 技术的主要知识领域，帮助规划学习顺序，并建立各主题之间的联系。

## 一、Prompt Engineering（提示词工程）

**学习重点：** 如何通过清晰的指令、上下文、约束和输出格式，引导大语言模型完成任务。

学习内容：

- Prompt 的基本结构
- 角色、任务、上下文与约束
- 提示词模板设计
- 提示词测试与迭代优化

学习入口：[提示词工程入门](/ai/prompt/)

## 二、RAG（检索增强生成）

**学习重点：** 如何让大语言模型结合外部知识回答问题，降低对模型内部知识的单独依赖。

计划学习：

- RAG 的基本原理
- 文档解析与切分
- Embedding 与向量检索
- 检索、重排与生成
- RAG 效果评估

## 三、MCP（模型上下文协议）

**学习重点：** 理解 AI 应用如何通过统一协议连接外部工具和数据源。

计划学习：

- MCP 的基本概念
- MCP Host、Client 与 Server
- Tools、Resources 与 Prompts
- MCP 的使用场景与安全注意事项

## 四、Agent（智能体）

**学习重点：** 理解 AI 如何围绕目标进行任务规划、调用工具并执行多步骤工作。

计划学习：

- Agent 的基本概念
- 任务规划与执行
- 工具调用
- 状态与记忆
- 结果检查与错误处理

## 五、AI 数据基础设施

**学习重点：** 理解数据存储、检索和处理能力如何支持 AI 应用。

计划学习：

- Data Lake 与 Lakehouse
- 向量数据与向量数据库
- 多模态数据
- 数据准备与检索
- 数据基础设施与 RAG 的关系

## 六、建议学习顺序

1. Prompt Engineering：学习如何清晰地描述任务。
2. RAG：理解 AI 应用如何利用外部知识。
3. MCP：理解 AI 应用如何连接工具与数据源。
4. Agent：理解多步骤任务规划与执行。
5. AI 数据基础设施：结合具体应用理解底层数据能力，并深入准备 AI 数据湖工程师面试。

以上是初步学习路线。实际学习时，可以根据项目需求调整顺序，并通过实践不断完善知识地图。
