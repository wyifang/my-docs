# AI 学习中心

这里系统整理人工智能相关技术知识、实践经验和学习成果。

学习目标包括：

- 为 AI 数据湖工程师岗位面试做准备。
- 系统学习 Prompt Engineering、RAG、MCP 和 Agent 等 AI 技术。
- 建立可长期查阅和持续更新的技术知识库。
- 通过实战项目巩固知识，并积累 AI 技术文档工程师的专业作品。

## 学习路线

查看 [AI 知识地图](/ai/knowledge-map)，了解各个技术领域的学习重点和建议顺序。

## 知识领域

### [Prompt Engineering](/ai/prompt/)

学习提示词设计、上下文组织和结构化输出。

### [RAG](/ai/rag/)

学习检索增强生成的基本原理、技术流程和实践方法。

### [MCP](/ai/mcp/)

学习模型上下文协议，以及 AI 应用连接外部工具和数据源的方式。

### [Agent](/ai/agent/)

学习 AI Agent 的基本概念、任务规划、工具调用和执行流程。

### [AI 数据基础设施](/ai/data-infrastructure/)

学习 Data Lake、Lakehouse、向量数据及数据与 AI 的结合。
