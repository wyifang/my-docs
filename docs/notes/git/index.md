# Git 学习笔记

这里记录 Git 学习过程中的核心概念、常用命令和实践经验。

## 学习路线

建议按下面顺序阅读：

1. [Git 基础](/notes/git/basic)
2. [Git 分支](/notes/git/branch)
3. [Git 合并与冲突](/notes/git/merge)
4. [Git 远程仓库与同步](/notes/git/remote)

## 学习目标

完成这些内容后，你应该能够：

* 理解工作区、暂存区和本地仓库的区别。
* 创建、切换和管理分支。
* 理解分支合并及冲突处理流程。
* 使用 `fetch`、`pull` 和 `push` 与远程仓库同步。
