# 脚注

Markdown 可以使用脚注，在正文中添加补充说明。

## 1. 最基本的脚注

### Markdown 源码

```
Markdown 是一种轻量级标记语言。[^1]

[^1]: Markdown 的英文名称是 Markdown。
```

### 实际效果

Markdown 是一种轻量级标记语言。[^1]

[^1]: Markdown 的英文名称是 Markdown。

### 解释

这里有两个部分。

正文中的：

```
[^1]
```

表示：

**这里有一个脚注引用。**

文章后面的：

```
[^1]: Markdown 的英文名称是 Markdown。
```

表示：

**脚注的具体内容。**

两边的编号必须对应。

点击正文中的脚注编号，通常可以跳转到页面底部的脚注内容。

## 2. 多个脚注

### Markdown 源码

```
VitePress 使用 Vite 作为构建工具。[^1]

Markdown 可以使用简单的标记语法。[^2]

[^1]: VitePress 官方文档介绍了它与 Vite 的关系。

[^2]: Markdown 的语法通常比 HTML 更简洁。
```

### 实际效果

VitePress 使用 Vite 作为构建工具。[^1]

Markdown 可以使用简单的标记语法。[^2]

[^1]: VitePress 官方文档介绍了它与 Vite 的关系。

[^2]: Markdown 的语法通常比 HTML 更简洁。

### 解释

这里有两个脚注：

`[^1]` 对应：

```
[^1]: VitePress 官方文档介绍了它与 Vite 的关系。
```

`[^2]` 对应：

```
[^2]: Markdown 的语法通常比 HTML 更简洁。
```

因此可以在同一篇文章中使用多个脚注。

---

## 3. 脚注的作用

脚注特别适合放：

* 补充说明
* 资料来源
* 术语解释
* 不希望打断正文的额外信息

例如：

### Markdown 源码

```
Git 是一个分布式版本控制系统。[^1]

[^1]: Git 最初由 Linus Torvalds 创建。
```

### 实际效果

Git 是一个分布式版本控制系统。[^1]

[^1]: Git 最初由 Linus Torvalds 创建。

这样正文可以保持简洁，而额外信息放在脚注中。

---

## 4. 脚注也可以包含 Markdown

这是脚注一个很有用的特点：

**脚注内容本身也可以使用 Markdown 语法。**

例如，可以在脚注中使用：

* 粗体
* 行内代码
* 链接
* 其他 Markdown 格式

### Markdown 源码

```
Markdown 是一种轻量级标记语言。[^1]

[^1]: Markdown 可以使用 **粗体**、`代码` 等 Markdown 语法。
```

### 实际效果

Markdown 是一种轻量级标记语言。[^1]

[^1]: Markdown 可以使用 **粗体**、`代码` 等 Markdown 语法。

注意观察页面底部的脚注：

* `**粗体**` 会显示成**粗体**
* `` `代码` `` 会显示成 `代码`

这说明：

**脚注不是只能放普通文字，它本身也是 Markdown 内容。**

---

## 5. 脚注中使用链接

脚注中还可以放链接。

### Markdown 源码

```
VitePress 是我们现在使用的文档工具。[^1]

[^1]: 可以参考 [VitePress 官方文档](https://vitepress.dev/)。
```

### 实际效果

VitePress 是我们现在使用的文档工具。[^1]

[^1]: 可以参考 [VitePress 官方文档](https://vitepress.dev/)。

这样可以把资料来源放到脚注中，而不会让正文变得杂乱。
