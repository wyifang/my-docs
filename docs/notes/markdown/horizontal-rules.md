# 分隔线

Markdown 可以使用分隔线把不同内容区域分开。

## 1. 最基本的分隔线

### Markdown 源码

```
---
```

### 实际效果

---

三个或更多的 `-` 可以创建一条水平分隔线。

---

## 2. 使用星号

### Markdown 源码

```
***
```

### 实际效果

---

三个或更多的 `*` 也可以创建分隔线。

---

## 3. 使用下划线

### Markdown 源码

```
___
```

### 实际效果

---

三个或更多的 `_` 也可以创建分隔线。

---

## 4. 最常用的写法

在实际 Markdown 文档中，我们通常使用：

```
---
```

因为这种写法最直观，也比较容易阅读。

例如：

```
## Git

Git 是一个版本控制系统。

---

## GitHub

GitHub 是一个代码托管平台。
```

实际效果：

## Git

Git 是一个版本控制系统。

---

## GitHub

GitHub 是一个代码托管平台。

---

## 5. 注意

分隔线和列表都可能使用 `-`，但是写法不同。

列表：

```
- 苹果
- 香蕉
- 橙子
```

分隔线：

```
---
```

区别在于：

* `-` + 空格 + 文字 → 列表
* 连续三个或更多 `-` → 分隔线

---

## 6. 实践练习

自己创建一个简单的文档结构：

```
# 我的学习笔记

## Git

我正在学习 Git。

---

## Markdown

我正在学习 Markdown。
```

观察 `---` 在页面上产生的效果。
