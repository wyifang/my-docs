# Emoji 和特殊字符

Markdown 文档中可以直接使用 Emoji 和很多 Unicode 特殊字符。

它们特别适合用来让文档更加直观。

---

## 1. 直接输入 Emoji

最简单的方法就是直接输入 Emoji。

### Markdown 源码

```
# 学习计划 📚

- 学习 Markdown ✍️
- 学习 Git 🌱
- 学习 VitePress 🚀
```

### 实际效果

# 学习计划 📚

* 学习 Markdown ✍️
* 学习 Git 🌱
* 学习 VitePress 🚀

Emoji 本质上也是 Unicode 字符，所以可以直接出现在 Markdown 文档中。

---

## 2. 使用 Emoji 表示状态

Emoji 可以帮助我们快速表达状态。

例如：

### Markdown 源码

```
- ✅ 已完成
- 🔄 进行中
- ⏳ 待完成
- ❌ 未完成
```

### 实际效果

* ✅ 已完成
* 🔄 进行中
* ⏳ 待完成
* ❌ 未完成

这种方式在学习笔记、项目文档和任务清单中很常见。

---

## 3. Emoji 和任务列表一起使用

还可以把 Emoji 和任务列表结合起来。

### Markdown 源码

```
- [x] 📚 学习 Markdown
- [x] 🌱 学习 Git
- [ ] 🚀 学习 VitePress
- [ ] 🌐 发布网站
```

### 实际效果

* [x] 📚 学习 Markdown
* [x] 🌱 学习 Git
* [ ] 🚀 学习 VitePress
* [ ] 🌐 发布网站

这样可以同时看到：

* 任务是否完成
* 任务是什么

## 4. 常见的特殊字符

Markdown 文档中也经常会使用一些特殊字符。

例如：

### Markdown 源码

```
✓ ✗
© ® ™
§ №
± × ÷
≤ ≥ ≠
→ ⇒
★ ☆
♥ ♡
```

### 实际效果

→ ← ↑ ↓

✓ ✗

© ® ™

§ №

± × ÷

≤ ≥ ≠

→ ⇒

★ ☆

♥ ♡

这些字符同样可以直接放进 Markdown 文档。

## 5. Emoji 和 HTML 实体

HTML 还提供了一种表示特殊字符的方法：

**HTML 字符实体。**

例如：

### Markdown 源码

```
&copy;
&reg;
&trade;
&lt;
&gt;
&amp;
```

### 实际效果

©

®

™

<

>

&

例如：

`&copy;` 表示 ©。

`&lt;` 表示 `<`。

`&gt;` 表示 `>`。

`&amp;` 表示 `&`。

---

## 6. 为什么有时候需要 HTML 实体？

假设我们想在页面中显示：

```
<
```

直接写 `<` 有时候可能会被 Markdown 或 HTML 当成标签的一部分。

这时候可以使用：

```
&lt;
```

最终显示：

<

同样：

```
&gt;
```

会显示：

>

所以 HTML 实体可以帮助我们安全地显示某些特殊字符。

## 7. Emoji、特殊字符和转义的区别

这三个概念容易混淆。

### Emoji

例如：

```
🚀 📚 ✅
```

直接写即可。

### 普通特殊字符

例如：

```
→ ★ © ±
```

通常也可以直接写。

### Markdown 特殊字符

例如：

```
* # [ ] >
```

这些字符在 Markdown 中有特殊含义。

如果希望它们按照普通字符显示，可以使用：

```
\*

\#

\[ \]

\>
```

所以：

**Emoji 和普通 Unicode 字符通常直接写。**

**Markdown 特殊字符需要根据情况使用转义或行内代码。**

## 10. 这一课最重要的知识

记住三个原则：

**Emoji：通常可以直接输入。**

**Unicode 特殊字符：通常也可以直接输入。**

**Markdown 特殊字符：如果不希望它被 Markdown 解释，可以使用转义或行内代码。**

例如：

```
🚀

©

→
```

这些通常可以直接使用。

而：

```
\#

\*

\[
```

则是在告诉 Markdown：

**“把这个符号当成普通字符。”**
