# 转义字符

Markdown 中有一些特殊字符具有特殊含义。

例如：

* `*` 可以表示强调
* `#` 可以表示标题
* `-` 可以表示列表
* `[` 和 `]` 可以参与创建链接

如果我们想让这些符号按照普通文字显示，就需要使用**转义字符**。

---

## 1. 什么是转义？

Markdown 使用反斜杠 `\` 作为转义符。

基本形式：

```
\特殊字符
```

意思是：

**告诉 Markdown：后面的特殊字符不要按照 Markdown 语法解释。**

---

## 2. 转义星号

正常情况下：

### Markdown 源码

```
**这是粗体**
```

### 实际效果

**这是粗体**

因为 `**` 在 Markdown 中有特殊含义。

如果想让 `**` 原样显示，可以使用转义：

### Markdown 源码

```
\*\*这是普通文字\*\*
```

### 实际效果

**这是普通文字**

这里的 `\` 告诉 Markdown：

**不要把 `*` 当成 Markdown 强调语法。**

---

## 3. 转义井号

正常情况下：

### Markdown 源码

```
# 这是标题
```

### 实际效果

# 这是标题

因为 `#` 在行首可以表示标题。

如果想显示一个普通的 `#`：

### Markdown 源码

```
\# 这不是标题
```

### 实际效果

# 这不是标题

这里的 `#` 会作为普通字符显示。

---

## 4. 转义方括号

方括号可以参与 Markdown 链接语法。

例如：

### Markdown 源码

```
[VitePress](https://vitepress.dev/)
```

### 实际效果

[VitePress](https://vitepress.dev/)

如果只是想显示方括号：

### Markdown 源码

```
\[这只是普通文字\]
```

### 实际效果

[这只是普通文字]

---

## 5. 常见的 Markdown 特殊字符

Markdown 中比较常见的特殊字符包括：

| 字符      | 常见作用      |
| ------- | --------- |
| `\`     | 转义        |
| `` ` `` | 行内代码、代码块  |
| `*`     | 强调、列表     |
| `_`     | 强调        |
| `#`     | 标题        |
| `-`     | 列表、分隔线    |
| `+`     | 列表        |
| `.`     | 有序列表中的一部分 |
| `[` `]` | 链接、脚注     |
| `(` `)` | 链接        |
| `!`     | 图片        |
| `>`     | 引用        |

当这些字符具有特殊含义，但你又希望它们按照普通字符显示时，可以考虑转义。

---

## 6. 一个实际例子

假设我们正在写 Markdown 教程。

我们想告诉读者：

> Markdown 中使用 `#` 创建标题。

### Markdown 源码

```
Markdown 中使用 \# 创建标题。
```

### 实际效果

Markdown 中使用 # 创建标题。

这里我们真正想显示的是：

`#`

而不是让它成为一个标题。

---

## 7. 转义和行内代码的区别

如果只是想展示 Markdown 语法本身，很多时候使用**行内代码**会更加方便。

例如：

### Markdown 源码

```
Markdown 使用 `#` 创建标题。
```

### 实际效果

Markdown 使用 `#` 创建标题。

这里的 `#` 被放进了行内代码中，因此 Markdown 不会把它解释成标题。

所以在实际写文档时：

**介绍一个 Markdown 符号时，通常可以优先考虑使用行内代码。**

例如：

```
使用 `#` 创建一级标题。
```

而不是：

```
使用 \# 创建一级标题。
```

---

## 8. 什么时候使用转义？

转义最适合这样的情况：

**你确实需要让 Markdown 把一个特殊字符当成普通字符处理。**

例如：

```
\* 这不是强调
```

或者：

```
\# 这不是标题
```

或者：

```
\[这不是链接\]
```

# Markdown 符号

如果想让这些符号按照普通字符显示，可以使用反斜杠进行转义。

1. 哪些符号会被 Markdown 解释？

3. 反斜杠 `\` 在这里起到了什么作用？

---

## 10. 这一课最重要的知识

Markdown 中：

```
\特殊字符
```

可以让特殊字符失去 Markdown 的特殊含义。

最简单的理解：

**转义 = 告诉 Markdown：“这个符号只是普通字符，不要解释它。”**

另外要记住：

**如果只是为了展示 Markdown 语法本身，行内代码 `` `...` `` 往往更加直观。**
