# 表格

Markdown 可以使用简单的符号创建表格。

## 1. 最基本的表格

### Markdown 源码

```
| 姓名 | 年龄 | 城市 |
| --- | --- | --- |
| 小明 | 15 | 北京 |
| 小红 | 16 | 上海 |
| 小刚 | 15 | 广州 |
```

### 实际效果

| 姓名 | 年龄 | 城市 |
| -- | -- | -- |
| 小明 | 15 | 北京 |
| 小红 | 16 | 上海 |
| 小刚 | 15 | 广州 |

---

## 2. 表格的基本结构

表格的第一行通常是表头。

例如：

```
| 姓名 | 年龄 | 城市 |
```

其中：

* `姓名` 是第一列
* `年龄` 是第二列
* `城市` 是第三列

第二行：

```
| --- | --- | --- |
```

用来分隔表头和表格内容。

后面的每一行就是具体的数据。

---

## 3. 表格的基本语法

一个最简单的表格可以写成：

```
| 第一列 | 第二列 |
| --- | --- |
| 内容 1 | 内容 2 |
| 内容 3 | 内容 4 |
```

实际效果：

| 第一列  | 第二列  |
| ---- | ---- |
| 内容 1 | 内容 2 |
| 内容 3 | 内容 4 |

你可以把它理解成：

```
| 表头 | 表头 |
| --- | --- |
| 数据 | 数据 |
| 数据 | 数据 |
```

## 4. 设置文字对齐方式

Markdown 表格还可以设置对齐方式。

### 左对齐

### Markdown 源码

```
| 姓名 | 年龄 |
| :--- | :--- |
| 小明 | 15 |
| 小红 | 16 |
```

### 实际效果

| 姓名 | 年龄 |
| :- | :- |
| 小明 | 15 |
| 小红 | 16 |

---

### 居中

### Markdown 源码

```
| 姓名 | 年龄 |
| :---: | :---: |
| 小明 | 15 |
| 小红 | 16 |
```

### 实际效果

|  姓名 |  年龄 |
| :-: | :-: |
|  小明 |  15 |
|  小红 |  16 |

---

### 右对齐

### Markdown 源码

```
| 姓名 | 年龄 |
| ---: | ---: |
| 小明 | 15 |
| 小红 | 16 |
```

### 实际效果

| 姓名 | 年龄 |
| -: | -: |
| 小明 | 15 |
| 小红 | 16 |

## 5. 技术文档中的实际应用

表格特别适合整理命令。

例如：

### Markdown 源码

```
| 命令 | 作用 |
| --- | --- |
| `git status` | 查看当前状态 |
| `git add .` | 添加文件 |
| `git commit` | 创建提交 |
| `git push` | 推送到远程仓库 |
```

### 实际效果

| 命令           | 作用      |
| ------------ | ------- |
| `git status` | 查看当前状态  |
| `git add .`  | 添加文件    |
| `git commit` | 创建提交    |
| `git push`   | 推送到远程仓库 |

注意：表格单元格里面也可以使用其他 Markdown 语法。

例如这里的命令使用了行内代码。
