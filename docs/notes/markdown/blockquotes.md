# 引用

Markdown 可以使用 `>` 创建引用。

## 1. 最基本的引用

### Markdown 源码

```
> 这是一段引用文字。
```

### 实际效果

> 这是一段引用文字。

### 解释

在文字前面加一个：

```
>
```

就可以创建引用。

---

## 2. 多行引用

### Markdown 源码

```
> 这是第一行。
> 这是第二行。
> 这是第三行。
```

### 实际效果

> 这是第一行。
> 这是第二行。
> 这是第三行。

每一行前面都可以写 `>`。

---

## 3. 引用中使用 Markdown

引用里面也可以使用其他 Markdown 语法。

### Markdown 源码

```
> **重要：** 请先保存文件。
>
> 然后再运行 `npm run dev`。
```

### 实际效果

> **重要：** 请先保存文件。
>
> 然后再运行 `npm run dev`。

这说明 Markdown 语法可以组合使用。

---

## 4. 嵌套引用

引用还可以嵌套。

### Markdown 源码

```
> 第一层引用
>
> > 第二层引用
```

### 实际效果

> 第一层引用
>
> > 第二层引用

第二个 `>` 会形成更深一层的引用。

---

## 5. 引用和普通段落的区别

普通文字：

```
这是一段普通文字。
```

实际效果：

这是一段普通文字。

引用：

```
> 这是一段引用文字。
```

实际效果：

> 这是一段引用文字。

最重要的区别就是：

**引用前面有 `>`。**

---

## 6. 实践练习

自己创建一个引用。

要求：

1. 至少两行
2. 第一行使用粗体强调一个关键词
3. 第二行使用一个行内代码

例如：

```
> **注意：** 修改配置文件之前，请先备份。
>
> 修改后运行 `npm run dev` 检查结果。
```
