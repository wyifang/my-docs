
# 文字强调：粗体、斜体与删除线

Markdown 可以通过简单的符号突出文字。

## 1. 粗体（Bold）

在文字两侧各加两个星号 `**`，即可显示为粗体。

例如：

**这是粗体文字。**

源码：

    **这是粗体文字。**

也可以使用两个下划线：

    __这是粗体文字。__

## 2. 斜体（Italic）

在文字两侧各加一个星号 `*`，即可显示为斜体。

例如：

*这是斜体文字。*

源码：

    *这是斜体文字。*

也可以使用一个下划线：

    _这是斜体文字。_

## 3. 删除线（Strikethrough）

在文字两侧各加两个波浪号 `~~`，即可显示删除线。

例如：

~~这是删除的文字。~~

源码：

    ~~这是删除的文字。~~

## 4. 混合使用

粗体和斜体可以组合使用：

***这是粗体加斜体。***

源码：

    ***这是粗体加斜体。***

## 5. 实践练习

请尝试写出下面三句话：

- 一句粗体文字：这是重点。
- 一句斜体文字：这是补充说明。
- 一句删除线文字：这是已经取消的内容。
