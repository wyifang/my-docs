# 标题与段落

Markdown 可以用简单的符号组织文档结构。

## 1. 标题

在文字前添加 `#`，就可以创建标题。

例如：

    # 一级标题
    ## 二级标题
    ### 三级标题

`#` 的数量越多，标题层级越低，通常最多使用六级标题。

## 2. 段落

段落之间空一行，就会形成新的段落。

例如：

    这是第一段。

    这是第二段。

## 3. 换行

如果希望在同一个段落中换行，可以在行末添加两个空格，再按回车。

例如：

    第一行  
    第二行

也可以使用 HTML 的 `<br>` 标签：

    第一行<br>
    第二行

## 4. 实践练习

试着用 Markdown 写出下面的结构：

- 一个一级标题：我的学习计划
- 一个二级标题：本周目标
- 两个段落，分别描述学习目标和学习安排
