# 📝 Markdown 学习笔记

记录 Markdown 的常用语法、排版技巧，以及在 VitePress 文档中的应用。

## 📖 学习目录

### 基础语法

* 标题与段落
* 粗体、斜体与删除线
* 有序列表与无序列表
* 链接与图片
* 行内代码与代码块

### 进阶应用

* 表格
* 引用
* HTML 与 Markdown 混合使用
* VitePress 扩展语法

## 🎯 学习目标

掌握常用 Markdown 语法，能够独立编写结构清晰、易于阅读的技术文档。
