

# Markdown 学习笔记

这里记录 Markdown 的常用语法、使用示例和实践练习。

本课程以实际编写技术文档为目标，所有示例都可以在本地 VitePress 项目中练习。

## 学习路线

建议按照以下顺序学习。

### 一、基础排版

学习如何组织文档内容。

- [标题与段落](./headings-and-paragraphs)
- [文字强调](./text-emphasis)
- [列表](./lists)
- [引用](./blockquotes)
- [分隔线](./horizontal-rules)

### 二、链接与媒体

学习如何连接页面、展示图片。

- [链接](./links)
- [图片](./images)

### 三、代码与数据展示

学习如何展示代码和结构化信息。

- [代码](./code)
- [表格](./tables)

### 四、辅助功能与特殊语法

学习任务跟踪、补充说明和特殊字符处理。

- [任务列表](./task-lists)
- [脚注](./footnotes)
- [HTML 与 Markdown](./html)
- [转义字符](./escape)
- [Emoji 和特殊字符](./emoji)

## 如何使用这些笔记

1. 先阅读 Markdown 源码。
2. 再观察页面实际效果。
3. 理解语法为什么会产生这种效果。
4. 在自己的 Markdown 文件中修改示例。
5. 保存后回到浏览器检查结果。

## 学习目标

完成这些内容后，你应该能够：

- 使用 Markdown 编写结构清晰的文档。
- 添加链接、图片、代码块和表格。
- 使用任务列表记录学习进度。
- 理解 Markdown 与 HTML 的基本关系。
- 在 VitePress 中组织和展示 Markdown 文档。
