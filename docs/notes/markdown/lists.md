# 列表

Markdown 可以很方便地创建列表。

## 1. 无序列表

在每一行前面加 `-`，可以创建无序列表。

例如：

- 苹果
- 香蕉
- 橙子

源码：

    - 苹果
    - 香蕉
    - 橙子

也可以使用 `*`：

* 苹果
* 香蕉
* 橙子

## 2. 有序列表

在每一行前面加数字和英文句号，可以创建有序列表。

例如：

1. 第一步
2. 第二步
3. 第三步

源码：

    1. 第一步
    2. 第二步
    3. 第三步

## 3. 嵌套列表

列表还可以嵌套。

例如：

- 水果
  - 苹果
  - 香蕉
  - 橙子
- 蔬菜
  - 西红柿
  - 黄瓜
  - 土豆
